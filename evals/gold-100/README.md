## پروتکل (ویرایش ۲)

1. **کورکورانه:** برچسب‌زن فقط caption را ببیند؛ خروجی موتور هرگز دیده نشود.
2. **قیمت:** «۵۵۰💸»=۵۵۰٬۰۰۰؛ «۴/۸۰»=۴٬۸۰۰٬۰۰۰؛ «حجم/وزن/ساعت» هرگز قیمت نیست؛
   بدون عدد = null (حدس ممنوع).
3. **دسته:** خانواده‌ی غالبِ محصول؛ توصیفگرهای عمومیِ فروشگاهی تعیین‌کننده نیستند؛
   هم‌سطح («آرایشی و پوستی») = null؛ پستِ بدون محصول = null.
4. **ویژگی:** colors=تناژها؛ sizes=شماره‌ی شید/سایز/حجمِ چسبیده به محصول.
5. **موجودی:** «موجود»←in_stock؛ دایرکت/کامنت/توافقی←on_request؛ وگرنه unknown.
6. **رأی‌گیری:** در اختلاف، annotator سوم (کاربر) در برگه‌ی تأیید تعیین می‌کند.

## ساخت و اجرا (از ریشه‌ی مخزن)

```bash
python evals/gold-100/build_batch1.py     # ساخت/بازسازی samples.json
python -m peyja extract-text evals/gold-100/samples.json --out out/predictions.json
python -m peyja gold-score                # نمره + حکم گیت‌ها
python -m peyja gold-sheet                # برگه‌ی تأیید انسانی («یک نفر چک کند»)
```

## ساختار فایل‌ها

- `samples.json` — نمونه‌ها (ساخته‌شده توسط `build_batch1.py`؛ commit می‌شود).
- `build_batch1.py` — منبعِ ساخت + برچسب‌های annotator-A (پیش‌نویس → تأیید انسانی).
- `verification-sheet.md` — ☐ برگه‌ی تأیید انسانی (خروجی `gold-sheet`).
- `collection-sheet.md` — چک‌لیستِ برچسب‌زنیِ بچ‌های ۲ و ۳.
