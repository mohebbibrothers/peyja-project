# gold-100 — مجموعه‌داده‌ی طلایی ارزیابی

**روش ساخت (دستی، حرفه‌ای):**

1. از ۱۰ تا ۱۵ پیج کیف/کفش (کرال‌شده با `peyja crawl`) حدود ۱۰۰ رسانه‌ی دارای قیمت انتخاب کنید.
2. هر نمونه را **با دست** برچسب بزنید:
   - `price_toman`: قیمت واقعی به تومانِ کامل (مثلاً ۴۸۰۰۰۰۰ برای «۴/۸۰»)
   - `old_price_toman`: قیمت قبل از تخفیف (اگر هست)
   - `category`: دسته‌ی محصول (bags / shoes / ...)
   - `colors`, `sizes`, `materials`: ویژگی‌ها
   - `stock_state`: in_stock / out_of_stock / on_request
3. نمونه‌ها را در همین فایل `samples.json` نگه دارید (۴ نمونه‌ی الگو موجود است).
4. اجرا: `python evals/score.py --gold evals/gold-100/samples.json --pred out/products.json`

**قواعد بازی:**
- برچسب‌زننده نباید خروجی مدل را ببیند (کور).
- اعداد فارسی در کپشن را دقیقاً همان‌طور که انسان ایرانی می‌خواند برچسب بزنید («۴/۸۰» = ۴٬۸۰۰٬۰۰۰).
- هر اختلاف‌نظر بین دو برچسب‌زننده → نمونه‌ی سوم داوری می‌کند.

**گیت‌های Phase 1:** قیمت ≥ ۸۵٪ | دسته/ویژگی ≥ ۷۵٪
