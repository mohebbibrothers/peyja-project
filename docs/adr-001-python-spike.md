# ADR-001 — زبان و استک فاز یک

**تاریخ:** 2026-11-19 · **وضعیت:** پذیرفته‌شده

## زمینه
فاز یک «ستون فقرات داده» است: کرال، استخراج، ارزیابی. نیازمند سرعت توسعه،
کتابخانه‌های بالغ NLP/تصویر، و اسکریپت‌نویسی CLI. گیت‌های موفقیت، عددی و
قابل‌اندازه‌گیری‌اند (۸۵٪ قیمت، ۷۵٪ دسته) — نه کیفیت کد.

## تصمیم
**Python 3.11+** با FastAPI + SQLAlchemy-async + asyncpg + Typer + httpx + tenacity.
(در تضاد با معماری آینده‌ی TypeScript که در FINAL-PROPOSAL برای gateway/agent آمده؛
این تصمیم فقط برای spike است و با ADR-002 (لایه‌ی Provider) جداسازی شده.)

## علل
- سرعت توسعه‌ی استخراج متن/تصویر (regex فارسی، VLM) در پایتون بی‌رقیب است.
- pytest + ارزیابی عددی سریع.
- FastAPI برای وب‌هوک (raw body + HMAC) عالی است.

## پیامدها
- Gateway نهایی (TypeScript) بعداً بازنویسی می‌شود — قابل‌قبول برای spike.
- هر تماس با بیرون از `packages/peyja/provider/` ممنوع (Anti-Corruption Layer).
